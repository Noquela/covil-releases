# 🛖 Covil

Aplicativo de voz, texto e compartilhamento de tela para um grupo de amigos.

**[⬇️ Baixar a versão mais recente](https://github.com/Noquela/covil-releases/releases/latest)**

---

## Como instalar

1. Baixe o arquivo `.exe` na página acima.
2. Abra. O Windows vai mostrar **"O Windows protegeu o seu PC"** — isso é
   esperado: o instalador não é assinado por uma autoridade certificadora (o
   certificado custa algumas centenas de dólares por ano e não vale a pena
   para um app de cinco amigos). Clique em **Mais informações** e depois em
   **Executar assim mesmo**.
3. Na primeira vez o app pede um **código de convite**. Peça o seu ao Bruno —
   sem código não dá para criar conta, e é de propósito: é o que mantém a sala
   sendo só de vocês.
4. Depois disso, abrir o app já é estar dentro. Sem login toda vez.

## Atualizações

O app confere sozinho se tem versão nova e avisa. **Ele nunca reinicia no meio
de uma conversa ou transmissão** — só quando você clica para atualizar.

## Precisa de VPN?

Não. Voz e tela vão direto de uma máquina para a outra pela internet, sem
servidor no meio. É isso que faz o app não ter custo mensal.
